# Student Management System

A web-based Student Management System developed using Spring Boot, Java, MySQL, HTML, CSS, and JavaScript.

## Features

- Student Registration
- Student Login
- Add Student Records
- Update Student Details
- Delete Student Records
- View Student Information
- File Upload Support

## Technologies Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Maven
- Git & GitHub

## Project Structure

- src/
- uploads/
- pom.xml

## How to Run

1. Clone the repository
2. Open in IntelliJ IDEA
3. Configure MySQL database
4. Run the Spring Boot application
5. Open the browser and access the application
